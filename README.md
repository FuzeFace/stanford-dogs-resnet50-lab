# Лабораторная работа: классификация видео с использованием VideoPrism

## Цель работы
Целью данной работы было освоение методов классификации видео с использованием архитектуры **ResNet50** для классификации видео с датасета **HowTo100M | Hobbies** с помощью **VideoPrism** для извлечения признаков.

## Постановка задачи
В ходе работы был решён следующий набор задач:
1. Извлечение кадров из видеороликов с использованием библиотеки OpenCV.
2. Применение **VideoPrism** для извлечения визуальных признаков.
3. Обучение модели классификации поверх извлечённых признаков.
4. Оценка качества модели с использованием метрик: **Accuracy**, **Precision**, **Recall**, **F1-score**.

## Результаты
| Experiment | Precision | Recall | F1 |
|------------|----------|--------|----|
| **Pretrained + Adam** | 0.8350 | 0.8216 | 0.8203 |
| **Pretrained + Averaged Adam** | 0.8598 | 0.8496 | 0.8481 |
| **From scratch + Adam** | 0.0956 | 0.0979 | 0.0813 |

## Вывод
В ходе работы была реализована классификация действий в видеороликах на датасете **HowTo100M | Hobbies** с использованием **VideoPrism** для извлечения признаков.

- **Результаты** экспериментов показали, что **предобученные модели (ResNet50)** обеспечивают гораздо более высокое качество классификации по сравнению с обучением с нуля.
- **Лучший результат** по метрике F1 был достигнут с оптимизатором **Averaged Adam** в комбинации с предобученной моделью **ResNet50**:
  - Precision = 0.8598
  - Recall = 0.8496
  - F1 = 0.8481

Модель, обученная с нуля, показала **плохие результаты**, что является ожидаемым для такого сложного датасета при ограниченном числе эпох обучения.

Таким образом, наиболее эффективным подходом в данной работе оказалось **дообучение предобученной модели ResNet50 с использованием Averaged Adam**.
