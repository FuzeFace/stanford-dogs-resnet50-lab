# Лабораторная работа 1 — Классификация пород собак с использованием SimpleCNN и ResNet50

## Цель

Целью работы было **освоение применения алгоритмов глубокого обучения для классификации изображений**, а именно:
- Реализация нейронной сети с использованием архитектуры **ResNet50** и **SimpleCNN**.
- Проведение трех экспериментов:
  1. **Дообучение модели** с использованием предобученной **ResNet50** с оптимизатором **Adam**.
  2. **Дообучение модели с усреднением весов (Averaged Adam)**.
  3. **Обучение модели с нуля** с использованием **SimpleCNN** на оптимизаторе **Adam**.

## Задание

Задание включало:
1. Скачать датасет **Stanford Dogs Dataset**.
2. Разделить его на три части: обучающую (70%), валидационную (15%), тестовую (15%).
3. Реализовать нейронную сеть на основе:
    - **ResNet50** для предобучения.
    - **SimpleCNN** для обучения с нуля.
4. Провести два типа экспериментов:
    - Дообучение модели с использованием предобученной **ResNet50** с оптимизатором **Adam**.
    - Дообучение модели с использованием **Averaged Adam**.
    - Обучение модели с нуля с использованием **SimpleCNN** на оптимизаторе **Adam**.
5. Сравнить производительность моделей по метрикам **Precision**, **Recall**, **F1-score**.

## Методология

Для решения задачи был использован датасет **Stanford Dogs Dataset**, содержащий 120 классов собак с изображениями. В ходе работы были проведены следующие этапы:

1. **Загрузка данных** и разбиение на обучающую, валидационную и тестовую выборки в пропорции 70%, 15%, 15%.
2. **Аугментация данных** для обучения: **Random Resized Crop** и **Random Horizontal Flip**.
3. Использование архитектуры **ResNet50** для предобучения и **SimpleCNN** для обучения с нуля.
4. **Оптимизация** с использованием оптимизаторов:
    - **Adam** для дообучения предобученной модели.
    - **Averaged Adam** для улучшения стабильности.
    - **Adam** для обучения с нуля.
5. Сравнение результатов по **Precision**, **Recall** и **F1-score** на тестовой выборке.

## Результаты экспериментов

### Эксперимент 1: **Pretrained + Adam**

- Модель **ResNet50** была дообучена на **Stanford Dogs Dataset** с использованием **оптимизатора Adam**.
- Результаты:
    - **Precision**: 0.8356
    - **Recall**: 0.8151
    - **F1**: 0.8101

### Эксперимент 2: **Pretrained + Averaged Adam**

- Результаты:
    - **Precision**: 0.8569
    - **Recall**: 0.8487
    - **F1**: 0.8472

### Эксперимент 3: **Scratch + Adam**

- Модель **SimpleCNN** была обучена с нуля на **Stanford Dogs Dataset** с использованием **оптимизатора Adam**.
- Результаты:
    - **Precision**: 0.0957
    - **Recall**: 0.0978
    - **F1**: 0.0813
