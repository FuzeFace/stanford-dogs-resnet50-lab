# Лабораторная работа: Классификация изображений с использованием ResNet50

## Цель работы
Научиться реализовывать один из алгоритмов глубокого обучения для классификации изображений с использованием архитектуры **ResNet50**.

## Датасет
В данной лабораторной работе используется датасет **Stanford Dogs Dataset**, который включает в себя 120 классов собак. Датасет был разделён на обучающую, валидационную и тестовую выборки в соотношении 70%/15%/15%.

## Архитектура модели
В данной работе используется архитектура **ResNet50**, с двумя подходами:

1. **Дообучение предобученной модели**:
   - Используется предобученная модель **ResNet50** с оптимизатором **Adam** и **Averaged Adam**.
   
2. **Обучение с нуля**:
   - Модель **ResNet50** обучается с нуля с использованием оптимизатора **Adam**.

## Описание экспериментов

### Эксперимент 1: Pretrained + Adam
- **Модель**: ResNet50 (предобученная).
- **Оптимизатор**: Adam.
- **Графики**:
  - Потери и точность для тренировочных и валидационных данных.
- **Метрики**:
  - Precision: 0.8356
  - Recall: 0.8150
  - F1: 0.8101

### Эксперимент 2: Pretrained + Averaged Adam
- **Модель**: ResNet50 (предобученная).
- **Оптимизатор**: Averaged Adam.
- **Графики**:
  - Потери и точность для тренировочных и валидационных данных.
- **Метрики**:
  - Precision: 0.8569
  - Recall: 0.8487
  - F1: 0.8473

### Эксперимент 3: ResNet50 from scratch + Adam
- **Модель**: ResNet50 (обучение с нуля).
- **Оптимизатор**: Adam.
- **Графики**:
  - Потери и точность для тренировочных и валидационных данных.
- **Метрики**:
  - Precision: 0.0956
  - Recall: 0.0978
  - F1: 0.0813

## Итоговые результаты
| Эксперимент                         | Precision | Recall | F1    |
|-------------------------------------|-----------|--------|-------|
| Pretrained + Adam                   | 0.8356    | 0.8150 | 0.8101|
| Pretrained + Averaged Adam          | 0.8569    | 0.8487 | 0.8473|
| ResNet50 from scratch + Adam        | 0.0956    | 0.0978 | 0.0813|

## Выводы

1. **Дообучение предобученной модели**:
   - Эксперимент с **Adam** показал хорошие результаты с **Precision = 0.8356**, **Recall = 0.8150** и **F1 = 0.8101**.
   - **Averaged Adam** немного улучшил результаты с **Precision = 0.8569**, **Recall = 0.8487** и **F1 = 0.8473**.
   
2. **Обучение модели с нуля**:
   - Эксперимент с обучением модели с нуля дал гораздо хуже результаты, с **Precision = 0.0956**, **Recall = 0.0978** и **F1 = 0.0813**.
   - Это подчеркивает важность использования предобученных моделей, которые уже имеют опыт работы с похожими задачами.
